**（1）制作アプリのタイトル**
「JavaScript Learning Lab」

**（2）制作アプリの説明（40文字程度）**
・JavaScript初心者を対象に、実際にアプリを操作しながら、コードの実行過程を視覚的に学べるWebアプリ。
・画面左側でアプリ画面を操作すると、右側にJavaScriptの実行コード・変数の変化・処理ログが段階的に表示される。
・コードを自分で読み解き、処理の仕組みを理解して、適切な修正指示を出せるようになることを目指す。

**（3）工夫した点・こだわった点**
・処理の可視化：アプリの操作に連動して、コードの実行過程や変数の変化を段階的に表示。
・直感的なUI：左側にアプリ、右側に学習パネルを配置し、操作と処理の関係を分かりやすく設計。
・自分のペースで学習：ステップ再生・一時停止・コードのハイライト機能を実装。
・初心者向けの解説：コード辞典を用意し、専門用語や構文を具体例とともに解説。
・段階的な学習設計：じゃんけんなど身近な題材を使い、基礎から少しずつ学べる構成にした（提出次はLevel1でタイムアップ！！）

**（4）難しかった点・次回トライしたいこと（または機能）**
・処理と表示の連動：アプリの操作に合わせて、JavaScriptの実行過程や変数の変化を正確に表示すること。
・ステップ再生の制御：一時停止・再開・ステップ移動を実装し、処理ログとの整合性を保つこと。
・初心者向けの解説：専門用語をできるだけ使わず、コードの役割や実行結果を分かりやすく説明すること。
・UIの設計：アプリの操作性と学習パネルの情報量を両立し、見やすいレイアウトにまとめること。
・AIとの共同開発：生成されたコードの内容を理解し、意図した動作になるよう具体的な修正指示を出すこと。
